Frequently asked questions

Are my files uploaded?

The tools are designed to process selected files in your browser. The page loads supporting JavaScript libraries from external CDNs, so review the deployed code and dependencies before using highly confidential documents.

Why did a conversion fail?

Check that your file is valid and not password-protected, try a smaller file, and make sure your internet connection is working. Some files may use features that this version does not support.

Why is a large file slow on my phone?

Processing depends on your device's memory, browser, file size and number of pages. If a task fails, close unused tabs and try a smaller file.

Which tools are available?

This version includes Image to PDF, Merge PDF and PDF to JPG. Always open the downloaded result to confirm it meets your needs.

Privacy and service limitations

File processing

PDF Dost is designed to process selected files locally in your browser; this page does not intentionally send the selected files to a PDF conversion server. Supporting JavaScript libraries are loaded from third-party content delivery networks (CDNs), which may receive ordinary connection information when your browser requests those files.

Compatibility and performance

Processing can fail for damaged, encrypted or password-protected PDFs and for files that exceed the available memory or processing capacity of your device. Large files may take longer, especially on mobile phones. An internet connection is required to load the supporting libraries.

Important privacy note

Do not use this service for highly confidential documents unless you have reviewed the deployed source code, external dependencies and hosting setup. If analytics, advertising or other third-party services are added later, this policy must be updated to accurately explain their data collection and use.
